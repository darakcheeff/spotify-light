# SpotifyLight

**SpotifyLight** — ультралегкий нативный клиент Spotify для Linux (Debian, Linux Mint, Ubuntu), написанный на **Rust** и **Slint UI**.

> **0% Electron. 0% Chromium / WebViews. Мгновенный запуск и потребление ~25-40 МБ RAM.**

---

## Особенности

- **Чистый нативный интерфейс**: декларативный Slint UI с точным воссозданием темной темы Spotify.
- **Полноценная компоновка (1:1 со скриншотами)**:
  - **Верхняя панель**: история навигации, поиск, профиль.
  - **Левый сайдбар («Моя медиатека»)**: фильтры (Плейлисты, Артисты, Альбомы), сортировка («Недавние ☰»), контекстные меню.
  - **Рабочая область**:
    - «Главная» (сетка быстрого доступа 2×4, релизы, карусели «Для тебя» и «Недавние»).
    - Страницы альбомов и плейлистов с адаптивным градиентом и таблицей треков.
    - Страницы артистов с топ-треками и дискографией.
    - Режим караоке / текстов песен (Lyrics) с плавной синхронизацией.
  - **Правая выдвижная панель**:
    - Вкладка **`[Очередь]`** (текущий трек и «Далее»).
    - Вкладка **`[Недавно прослушано]`** (история воспроизведения).
    - Вкладка **`[Connect]`** (выбор умных колонок Google Home, смартфонов, Smart TV).
  - **Нижний плеер-бар**: обложка, Like, контролы, скраббер, громкость, кнопка караоке и колонок.
- **Сетевое обнаружение колонок (Discovery)**:
  - Поиск локальных колонок через mDNS / DNS-SD (`_googlecast._tcp` и `_spotify-connect._tcp`).
  - Переключение вывода звука на Google Home в один клик.
- **Звуковое ядро**: нативный `librespot` (Rust) с выводом через PipeWire, PulseAudio или ALSA.
- **Интеграция с Linux Desktop**: D-Bus MPRIS2 (`org.mpris.MediaPlayer2`), системные мультимедиа-клавиши и апплет звука.

## Установка (.deb)

Готовый пакет совместим с **Debian 11, 12, 13** и **Linux Mint 20, 21, 22**:

```bash
sudo dpkg -i spotify-light_0.1.0_amd64.deb
# или
sudo apt install ./spotify-light_0.1.0_amd64.deb
```

## Сборка через GitHub Actions

Сборка пакета запускается вручную:
1. Перейдите во вкладку **Actions** в репозитории GitHub.
2. Выберите **Build Debian/Mint Package**.
3. Нажмите **Run workflow**.
4. Скачайте собранный `.deb` из вкладки Artifacts.
